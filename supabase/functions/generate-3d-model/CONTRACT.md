# generate-3d-model — contract

Photo → real GLB, generated by **TRELLIS 2** (Microsoft, MIT open source)
running on the founder's own PC as the GPU node. No hosted model APIs.

## Pieces
- **Panel** (`src/components/Modeler3D.tsx`): photo upload, tier pick,
  polls the job, shows the result in SpaceModelViewer + GLB download.
- **Function** (`index.ts`, this folder): auth + Global Credit charge
  (generate-sfh-image pattern: `ai_credits_consume` / refund via
  `ai_credits_grant` with ref `model3d:refund:<jobId>`), job state as
  JSON in the `studio-published` bucket under `models-3d/`.
- **PC node** (Python script on the founder's PC): polls `claim`, runs
  TRELLIS 2 locally, uploads the GLB, calls `complete`.

## Member actions (Authorization: Bearer <session>)
- `status` → `{ online, gpu, vramGb, tiers, prices }`. Online = a node
  heartbeat fresher than 90s. Tiers offered depend on the node's VRAM
  (512 needs ~12GB; 1024/1536 need ~24GB).
- `create` `{ imageDataUrl, tier }` → charges the tier price (admins 0),
  stores the photo, writes a `queued` job, returns `{ jobId, credits }`.
  503 `engine_offline` (no charge) when no node is live; 402
  `limit_reached` when out of Credits.
- `poll` `{ jobId }` → `{ status, modelUrl, error, tier }`
  (queued | running | done | failed). Jobs running >45min are failed
  and refunded.

## Node actions (header `x-node-key: <MODEL_NODE_KEY secret>`)
- `heartbeat` `{ gpu, vramGb }` — every ~30s while the node is up.
- `claim` → oldest queued job `{ job: { id, tier, imageUrl }, uploadUrl,
  publicUrl }`, or `{ job: null }`. Marks the job `running`.
- `complete` `{ jobId }` — after the GLB is uploaded to `uploadUrl`;
  the function verifies the file exists, then marks `done`.
- `fail` `{ jobId, error }` — marks `failed` and refunds the member.

## Prices (founder-suggested 2026-11-12, pending final approval)
512 → 5 Credits · 1024 → 10 Credits · 1536 → 15 Credits.
