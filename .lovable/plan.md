# Simplify the NET tab across all profiles

## Goal
Create one cleaner, flatter NET experience shared by startup, investor, mentor, advisor, accelerator, student, and member dashboards without changing search, filters, matches, connection states, messaging, or profile actions.

## Changes
- Replace the oversized decorative NET header on the startup dashboard with the same compact shared layout used elsewhere.
- Simplify the shared role filters into a restrained segmented row with counts and clear active state.
- Keep profile details readable while reducing decorative badges, boxed sub-sections, scale effects, gradients, and visual noise.
- Preserve business-card scanning, Connect, Requested, Message, View, Pass, Accept, and Decline behavior.
- Apply the result through the shared NET components so every profile type receives the same update.
