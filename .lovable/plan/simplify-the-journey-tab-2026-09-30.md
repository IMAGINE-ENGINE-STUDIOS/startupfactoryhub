# Simplify the Journey tab

## Goal
Make the shared Journey tab feel modern and uncluttered across every profile type, without changing progress data or actions.

## Changes
- Replace the large decorative progress header and separate step rail with one compact journey header containing progress, stage navigation, and the Add Step action.
- Present the selected stage as one clean content area with subtle dividers instead of stacked cards.
- Flatten the task checklist and Technology Readiness area so they read as sections within the selected stage.
- Simplify accelerator program journeys into clean rows inside one shared section.
- Preserve completion, undo, reset, custom-step, resources, mentor/advisor, and milestone functionality.

## Validation
- Confirm the Journey tab builds successfully.
- Check the shared tab at desktop and mobile widths for readable spacing and no overlapping controls.
